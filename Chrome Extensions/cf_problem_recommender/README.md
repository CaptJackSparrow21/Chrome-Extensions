# Chrome Extensions

A collection of useful browser extensions developed to improve productivity, simplify workflows, and enhance the developer experience.

## Extensions

### 1. CF Problem Recommender

A Chrome extension for Codeforces users that recommends popular problems they haven't solved yet.

**Features**
- Automatically detects the logged-in Codeforces handle.
- Recommends the top 5 most-solved unsolved problems.
- Filter problems by rating.
- Optional topic-tag filtering.
- Displays recommendations below the Codeforces activity heatmap.
- Responsive interface.

**Technology**
- JavaScript
- HTML
- CSS
- Chrome Extension Manifest V3
- Codeforces API

**Installation:** Open `brave://extensions` or `chrome://extensions`, enable Developer Mode, and select Load unpacked.
